## 4. КРАТКИЕ КОММЕНТАРИИ ПО ПУНКТАМ РЕЕСТРА

- **Формулировки актов** — согласуются со стороной заказчика до первого акта (каталог `01__Требования к оформлению\` в рамке пуст — риск отказа из-за формулировок); для N3 формулировки соответствуют протоколу разногласий (rev.02 v02), а не первоначальному тексту.
- **Привязка к оплате** — каждый акт закрывает строку реестра счетов ([README-invoice.md](../05__Счета/README-invoice.md)) и является основанием постоплаты.
- **Пустой реестр (п. 2)** — норма этапа исполнения; первая строка — по факту выставления первого акта.

## 5. ПОРЯДОК ВЕДЕНИЯ

1. Регистрируются выставление и подписание каждого документа (две даты, сторона, объём).
2. Указывается закрытый объём (позиция/экземпляр) и остаток по заказу.
3. Расхождения по формулировкам — строка реестра корректировок старта рамки.
4. Подписанные экземпляры — `03__Подписанный\`/`09__Подписанные документы\` по решению стороны; скан-копии — здесь.
