Заказ № 2 `8/2026-n2-горизонт` рамочного договора — **реверс-инжиниринг
постаматного вендингового аппарата Knowhy G80/master** и **адаптация программно-

заказчик подписал 20.10.2026, исполнитель — 21.10.2026 через ЭДО. Методика заказа
«анализ → ТЗ → адаптация ПТК → финальный прогон» — эталонная для N3 и
перспективного N5. Жизненный цикл ведётся в настоящей ИРП; рамка хранит
мастер-данные, юридический контур и перспективу N4–N7.
