## 4. КРАТКИЕ КОММЕНТАРИИ ПО ПУНКТАМ РЕЕСТРА

- **Переписка (п. 2)** — регламент: драфты в `00__draft\` (markdown), выпуск на бланке — за стороной исполнителя, выпущенный экземпляр — в корень каталога; тема письма переносится в реестр дословно, по ней письмо ищется в переписке.
- **Расхождения документов (п. 3)** — урегулируются единым письмом по реестру корректировок старта рамки, не раздельной перепиской.
- **Пустые каталоги (п. 3)** — на старте заказа норма; заполняются по факту событий.

## 5. ПОРЯДОК ВЕДЕНИЯ
